# sources/local —— 本地静态补充

把你自己手头的 m3u / txt 播放列表放进本目录（`*.m3u`、`*.m3u8`、`*.txt`），
`scripts/fetch_sources.py` 会在每轮采集时把它们与网络发现的源一起合入。

- 本目录内容**不受发现层管理**，也不会被淘汰规则删除，属于"人工兜底"。
- 支持两种格式：
  1. 标准 M3U：`#EXTM3U` + `#EXTINF:-1 group-title="央视",CCTV-1 综合` + 地址行；
  2. 纯文本：`央视,#genre#` 分段 + `频道名,http://...` 行。
- 同一条流会参与统一去重，不会因为放在本地就重复输出。
